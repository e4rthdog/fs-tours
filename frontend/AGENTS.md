# AGENTS.md (frontend)

Vue 3 single-page app using Quasar 2. See the root [AGENTS.md](../AGENTS.md) for shared rules (git, admin auth flow, setup) and [../api/AGENTS.md](../api/AGENTS.md) for the API contract.

## Stack rules

- Vue 3 with the Composition API (`<script setup>`). Follow the official Vue documentation and best practices.
- Pinia for state management and the official Vue Router.
- Latest Quasar framework and its components.
- **Do not use TypeScript.**
- Maps: Leaflet through `@vue-leaflet`.

## Commands

```bash
npm run dev       # development server
npm run build     # production build
npm run lint      # ESLint
npm run format    # Prettier
```

## Conventions

- `src/stores/fstours.js` is the single Pinia store. Put all API calls there, not in components.
- `MainLayout.vue` shares store methods with child components via provide/inject.
- Admin-only UI is gated on `isAdmin` in the store.
- Router is hash-based.
- Use scoped styles by default; theming goes through Quasar. Dark mode is the default (`quasar.config.js`).
- New components go in `src/components/`. Register them with `HeaderElements` only if they belong in the header toolbar.

## Generated and local files

- `src/version.js` - generated by `generate-version.js` on dev/build. Do not edit.
- `src/config/config.js` (from `config.example.js`) and `dist/` - not committed.
